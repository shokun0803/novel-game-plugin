# 「影の探偵」本格推理ゲーム シナリオ設計書（v2）

## ゲーム概要

**タイトル:** 影の探偵（Shadow Detective）
**ジャンル:** ハードボイルド・ミステリー ノベルゲーム
**シーン数:** 25シーン
**エンディング数:** 4種類（完全解決 / 部分解決 / 誤推理 / 袋小路）

## 設計方針（v1からの変更点）

v1は「アイテムを集めるとエンディングが変わる」だけの一本道に近い構成で、
シーンの使い回しが多く、探偵側の台詞にも不自然さが残っていた。
v2では次の方針で根本から作り直した。

1. **推理する体験を中心に据える** — 証拠集めの先に「黒幕は誰か / 誠は生きているか / どこにいるか」の
   3段階の推理フェーズを置き、プレイヤー自身が結論を選ぶ。誤答は誤推理エンドに直結する。
2. **証拠が推理を解錠する** — 各推理の正解選択肢は対応する証拠・証言フラグが無ければ表示されない。
   「わかっているのに選べない」のではなく「調べていないから思いつけない」体験になる。
3. **ハブ&スポーク構造** — 調査ハブ「事件簿」(シーン4)を中心に、行き先が調査の進捗フラグで
   動的に開閉する。同じシーンの再訪はなく、行き止まりも発生しない（状態空間探索で全数検証済み）。
4. **人物に裏の顔を持たせる** — 依頼人・美咲は電話の内容を隠しており、旧友・佐藤は借金のカタに
   誠の予定を漏らした密告者。証拠を突きつけることで初めて核心の証言が得られる。
5. **伏線と回収** — 無言電話（龍組の脅迫）、9時47分で止まった懐中時計（誠が意図的に残した目印）、
   半開きの隠し扉（高木側が帳簿を探して見つけられなかった痕跡）などをすべて終盤で回収する。

**登場人物・背景画像はv1の既存アセットのみを使用**（追加画像なし）。

## 事件の真相（ネタバレ）

- 黒崎誠の会社は、高木建設（高木社長 = "T.T."）が公共事業の裏金を洗浄するための経由地だった。
- 誠は「九月の送金を最後に降りる」と告げたため、高木は龍組の取り立て屋・権田に命じて
  失踪の夜、埠頭で誠を「回収」させ、海岸道路の果ての別荘に軟禁した。
- 目的は殺害ではなく、書斎から消えた裏帳簿の在処を吐かせ、沈黙させること。
- 誠は連れ去られる直前、妻から贈られた懐中時計をわざと落とした（発見者への目印）。
- 美咲にかかる夜中の無言電話は、権田による「沈黙の催促」。
- 佐藤は龍組への借金と引き換えに誠の予定を流していたが、罪悪感から写真を提供し、
  追及されると「権田の車が海岸道路（高木の別荘方面）へ向かった」という決定的証言をする。

## エンディング条件

| エンディング | シーン | 条件 |
|------------|-------|------|
| 完全解決 | 22 | シーン21で全証拠選択肢を選ぶ（懐中時計・佐藤の写真・美咲の告白・幹部の失言・佐藤の告白 のAND） |
| 部分解決 | 23 | シーン21で「まず彼を家に帰す」を選ぶ（常時選択可） |
| 誤推理 | 24 | 推理Ⅰ〜Ⅲのいずれかで誤答 |
| 袋小路 | 25 | シーン13で龍組に力ずくで踏み込む |

完全解決には、クリティカルパス外の任意調査（倉庫街の時計 → 美咲への提示 → 告白）まで
拾う必要があり、周回プレイの動機になる。

## プラグイン機能の網羅状況（サンプルとしての教材性）

| 機能 | 使用箇所 |
|------|---------|
| シーン到達時フラグ (`set_flags` / `_scene_arrival_flags`) | ほぼ全調査シーン |
| 選択肢のフラグ条件（state true/false・ANDロジック） | ハブ(4)ほか多数。false条件で「探索済みの行き先を隠す」 |
| 選択肢のsetFlags | 推理フェーズ(16-18)の回答記録 |
| セリフのフラグ条件 alternative表示 | 4, 11, 15, 17, 18（証拠に応じて独白が変化） |
| セリフのフラグ条件 hidden表示 | 10（告白済みなら含みのある独白が消える） |
| セリフごとの表情差分 (`dialogue_characters`) | 1, 2, 5, 6, 7, 10, 12, 13, 14, 15, 19, 21 |
| セリフ内の背景切替 (`dialogue_backgrounds`) | 20（自白中の回想で倉庫街に切替） |
| 複数エンディング (`is_ending` / `ending_text`) | 22-25 |
| ゲームオーバーテキスト | 「手掛かりは途絶えた」（通常到達しないフェイルセーフ） |

## 実装上の注意事項

1. **国際化:** すべてのテキストは `__( ..., 'novel-game-plugin-sample' )` でラップ。
   日本語訳は `languages/novel-game-plugin-sample-ja.po` / `.mo` に収録。
2. **フラグ照合はフラグ「名前」で行われる** — `flagConditions` / `setFlags` /
   フラグマスタの名前は同一のmsgidを共有し、翻訳後も一致が保たれる。
3. **保存形式:** `_dialogue_flag_conditions` はセリフindexをキーとした**配列**で保存する
   （フロント出力・管理画面と同じ形式。JSON文字列では機能しない）。
4. **選択肢の表示上限は4** — フラグ条件でのフィルタ後に4件へ切り詰められるため、
   どの状態でも同時に成立する選択肢が4件以下になるよう設計している（検証済み）。
5. **machine_name は `shadow_detective_v1` を維持** — 既存インストールを上書きしないため。
   既存環境で新シナリオを試す場合は、ゲームを削除してからプラグインを再有効化する。

## 検証

`scratchpad` の検証スクリプト（状態空間探索）で以下を確認済み:

- 全25シーン到達可能 / 4エンディングすべて到達可能
- どの到達可能状態でも選択肢は1〜4件（行き止まり・切り詰めなし）
- フラグ条件・setFlags・set_flags が参照する名前はすべてフラグマスタに存在
- セリフ配列（texts / speakers / backgrounds）の長さが全シーンで一致
